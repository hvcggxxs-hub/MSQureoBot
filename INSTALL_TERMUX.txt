تنبيه: Termux على أندرويد مناسب لتشغيل واجهة Telegram وبعض الخدمات، لكنه لا يدعم تشغيل متصفح Qureo عبر Playwright/Chromium بصورة موثوقة. لتشغيل جلسات Qureo استخدم Linux.

لترقية نسخة موجودة:
1) أوقف البوت القديم.
2) احتفظ بنسخة خاصة من .env ومجلد data كاملًا.
3) فك ضغط النسخة الجديدة في مجلد منفصل.
4) انسخ .env القديم إلى مجلد النسخة الجديدة. لا تستبدله بملف .env.example.
5) انقل data/users.enc.json إلى مجلد data في النسخة الجديدة.
6) حافظ على قيمة DATA_ENCRYPTION_KEY القديمة كما هي تمامًا، وعلى DATA_DIR نفسه.
7) نفّذ npm install
8) نفّذ npm run check
9) شغّل npm start

لا ترسل .env أو users.enc.json أو أي مفاتيح أو كلمات مرور إلى أي شخص.
لإنشاء صورة: أضف CF_ACCOUNT_ID وCF_API_TOKEN اختياريًا إلى .env ثم استخدم /image وصف الصورة.
للتفعيل: المستخدم يرسل /start ثم يطلب رمزًا، والمدير يصدره من لوحة /panel.
